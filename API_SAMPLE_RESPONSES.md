# API sample responses

Generated by `python -m scripts.generate_api_samples` against a fresh database, with LLM extraction and
LLM replies (`gemini-3.5-flash-lite`). Memory ids, timestamps, latencies and wording vary per run.
Extraction runs in a background worker, so a turn's own memories appear from the next turn onward.
A live turn recalls raw turns only from beyond the short-term window (10 turns), so in this short
session they appear only through `/recall`.

## 1. Health and active backends

```http
GET /health
```

```json
{
  "status": "ok",
  "extractor": "LLMExtractor(gemini-3.5-flash-lite)",
  "embeddings": "st:BAAI/bge-small-en-v1.5",
  "retrieval": "rrf: 10 memories + 5 raw turns"
}
```
