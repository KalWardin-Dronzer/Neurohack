LONG-FORM MEMORY SYSTEM ARCHITECTURE (v2)

Mermaid flowchart (paste into Mermaid Live Editor, GitHub, or any markdown viewer):

```mermaid
flowchart TD
    U[User turn] --> A["POST /sessions/{session_id}/turns"]

    subgraph FP[Fast path: synchronous]
        A --> B[Persist turn in SQLite]
        B --> C[Short-term window: last K turns]
        C --> D1["Dense ranking: bge-small-en-v1.5 cosine over a cached float32 matrix"]
        C --> D2["Lexical ranking: SQLite FTS5 BM25 with Porter stemming"]
        D1 --> F[Reciprocal Rank Fusion]
        D2 --> F
        F --> G["One value per subject+key slot, optional similarity floor, top k"]
        G --> E[Reply: LLM with dated memories, or rule-based fallback]
    end

    A --> Q[Queue extraction task]

    subgraph BG[Background worker]
        Q --> X["LLM structured extraction: JSON schema, Pydantic, evidence ids, ISO dates"]
        X -->|LLM unavailable| R[Regex fallback]
        X --> Y["Upsert: events accumulate; facts supersede within subject+key"]
        R --> Y
        Y --> Z1[Embed and store vector tagged with its model]
        Y --> Z2[Update FTS5 index]
    end

    subgraph BATCH[Batch ingestion, used by the LoCoMo benchmark]
        S[One session of turns and its date] --> X
    end

    Z1 --> D1
    Z2 --> D2
```

Request lifecycle:

1. The client sends a user turn.
2. The turn is stored, and the most relevant memories are retrieved by fusing the dense and BM25 rankings.
3. A reply is generated with those memories and returned immediately.
4. A background worker extracts typed memories from the turn, each citing the turns it came from.
5. A new value for an existing subject+key slot deprecates the old one; events accumulate.
6. The next turn retrieves from the updated store without replaying history.

Core records:

1. Turn: `session_id`, `turn_id`, `role`, `content`, `created_at`
2. Memory: `memory_id`, `type`, `subject`, `key`, `value`, `event_date`, `evidence`, `source_turn`,
   `confidence`, `status`, `supersedes_memory_id`
3. Embedding: `memory_id`, `model_id`, `dim`, float32 `vector`
